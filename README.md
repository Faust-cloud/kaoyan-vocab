## 为什么做这个

市面上的考研单词书,要么只给一个中文意思,要么信息堆得密密麻麻。这个项目想做的是:

- **重点词讲透:** 同义替换、常用搭配、易混辨析、真题风格例句都给全。
- **次要词点到为止:** 一行释义就够,不浪费注意力。
- **每个词给一个记忆钩子:** 用一句话说明它是怎么来的,有可靠词源就写出来,没有就直接写"来源不明",让你放心死记。

```
resist      v. 抵抗;忍住    ←  re-(回)+ sistere(站)→ 站着顶回去
prejudice   n. 偏见          ←  pre-(前)+ judicium(判断)→ 提前下的判断
huddle      v. 挤在一起      ←  来源不明
```

## ✨ 功能

| | |
|---|---|
| ⭐ **重点词分级** | 高频词放大展示,宽屏下分两栏:左边是释义和来源,右边是同义词、搭配和例句 |
| 🙈 **遮挡自测** | 一键模糊释义,先回想,再点开核对 |
| ☆ **错词本** | 标记没记住的词,集中复习 |
| ✓ **过遍打卡** | 每过完一个单元记一次,自动记录次数和时间,哪些单元过得少一眼就知道 |
| 🔢 **快速跳转** | 左右切换单元,也可以从数字格子直接跳到任意一个单元 |
| 🔊 **发音** | 自动挑选系统里音质最好的英语语音 |
| 🔍 **全文搜索** | 英文、中文、同义词都能搜 |
| 🌐 **中英界面** | 界面文字一键切换中文 / English |
| 🎨 **五套主题** | 纸本 / 青瓷 / 海盐 / 樱粉 / 夜读 |
| 💾 **备份与恢复** | 错词和打卡记录可以一起导出,换设备也不丢 |

## 🎯 设计理念

- **单词是主角。** 释义和用法放在最显眼的位置,来源只是辅助记忆的一句话。
- **详略分明。** 精力留给真正会考的词。
- **零依赖,纯静态。** 不用框架、不打包、不用后端,双击 `index.html` 就能用。

## 🗂️ 项目结构

```
├── index.html      # 页面、样式与交互逻辑
├── data.js         # Unit 1–6 词条
├── extra.js        # Unit 1–6 重点词扩展
└── units/          # Unit 6(后半)– 26,每个单元一个文件
```

每条词条是一行数据:

```js
["generate", "v. 产生;引起", "拉丁 generare(生育)→ 生出来 → 产生", "",
 { syn: "produce · create · bring about", ex: "...", exZh: "..." }]
```

## 🤖 制作过程

整个项目由 **Claude Opus 5.5** 在对话中完成:词条编写、页面设计、交互实现和数据校验都是它做的。

- **迭代轮次:** 30+ 轮人工反馈与修改
- **Token 消耗:** 输出约 40 万 token,累计处理数千万 token(含上下文缓存,估算值)

几次关键的修改:

- 第一版 Unit 7–21 质量下滑(例句变少、卡片合并),于是按 Unit 1–6 的标准全部重写。
- 每个单元都用脚本和原始词表逐词比对,确保不漏词也不多词。
- 界面经过多轮打磨:重点词呈现方式、例句字号、多主题配色、单元导航、发音质量、过遍打卡、中英界面切换。
