# 考研词汇

考研英语大纲词汇的网页版词书。词条按单元组织,每个词给出释义、来源和常用搭配,重点词另附同义替换、易混辨析和例句。

[在线使用](https://faust-cloud.github.io/kaoyan-vocab/)

## 内容

| 板块 | 范围 | 状态 |
|---|---|---|
| 必考词 | Unit 1–26 | 已完成 |
| 基础词 | Unit 1–30 | 已完成 |
| 简单基础词 | Unit 1–15 | 已完成 |
| 超纲词 | A–Y | 已完成 |

全书收录词条约 6,500 条:必考词 1,800 余条,基础词 2,504 条,简单基础词 1,183 条,超纲词 1,030 条。各板块均已与原始词表逐词核对。简单基础词和超纲词只给释义和构词,常见本族词标注"本族词"。

词条分两级:

- 重点词:释义、来源、同义替换、常用搭配、易混提示、例句
- 一般词:释义和一句来源说明

来源说明只保留对记忆有帮助的部分。词源不可考或与现代词义关系不大的,注明"来源不明"或只写构词。

```
resist     v. 抵抗;忍住      re-(回)+ sistere(站)→ 站着顶回去
prejudice  n. 偏见            pre-(前)+ judicium(判断)→ 提前下的判断
huddle     v. 挤在一起        来源不明
```

## 功能

- 遮挡模式:隐藏释义,点击卡片查看
- 错词本:标记未掌握的词,集中复习
- 过遍记录:按单元记录复习次数和时间
- 全文搜索:支持英文、中文释义和同义词
- 单词发音:使用系统内置的英语语音
- 界面语言:中文 / English
- 配色主题:5 套,含夜间模式
- 数据备份:错词和复习记录可导出、导入

学习记录保存在浏览器本地(localStorage),不上传任何数据。

## 使用

无需安装。下载仓库后用浏览器打开 `index.html` 即可。

```bash
git clone https://github.com/Faust-cloud/kaoyan-vocab.git
cd kaoyan-vocab
open index.html
```

## 目录结构

```
index.html     页面结构、样式和交互
data.js        必考词 Unit 1–6
extra.js       Unit 1–6 重点词的扩展字段
units/         u*.js 必考词 Unit 6(续)– 26
               b*.js 基础词 Unit 1–30
               s*.js 简单基础词 Unit 1–15
               x*.js 超纲词 A–Y
```

## 数据格式

每个单元是一个对象,词条按词形或词根分组:

```js
UNITS.push({
  id: "u7", name: "Unit 7",
  sections: [
    { t: "gen-", d: "gen = 生、种族", w: [
      ["generate", "v. 产生;引起", "拉丁 generare(生育)← genus(种族)", "", {
        syn: "produce · create · bring about",
        senses: ["generate income 创造收入"],
        ex: "...", exZh: "..."
      }]
    ]}
  ]
});
```

词条数组依次为:单词、释义、来源、关联提示、扩展字段(可选)。扩展字段为空即为一般词。

新增单元:在 `units/` 下新建文件,并在 `index.html` 中按顺序引入。
